# Pritesh Kumar — Personal Site

Built with Astro + Tailwind CSS. Hosted on Firebase.

## 🎨 Theme

Modern Cloud & Tech palette (Slate, Sky Blue `#38bdf8`, Electric Cyan `#06b6d4`, Warm Amber `#f59e0b`).

## 🚀 Launch & Deployment

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```

### Deploy to Firebase
```bash
npx firebase-tools deploy --only hosting
```
